# Q: Quelles sont les capacités de cette application ?

## Answer

HOUSE est une PWA de revision medicale avec 8 sections principales: accueil/dashboard (app/page.tsx), annales (scan+extraction IA de QCM), cours (bibliotheque de modules), assistant vocal (app/assistant/page.tsx), planning d'examens, revision/quiz, progression (stats), parametres (sauvegarde auto). Capacites transversales: extraction de questions par IA (locale Ollama ou API), reconnaissance et synthese vocale, base de donnees locale IndexedDB avec sync, sauvegarde automatique vers systeme de fichiers, PWA installable avec service worker offline.
